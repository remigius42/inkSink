## Electronics Assembly

### GPIO Pin Usage

**E-ink HAT uses (SPI + Control):**

- GPIO 8, 9, 10, 11 (SPI: CE0, MISO, MOSI, SCLK)
- GPIO 17, 24, 25 (RST, BUSY, DC)

**PiSugar 3 uses (I2C + Power):**

- GPIO 2, 3 (I2C: SDA, SCL)
- Pins 2, 4, 6 (5V, 5V, GND via pogo pins on underside)

**Available for buttons (~30+ pins):**

- GPIO 4, 5, 6, 7, 12, 13, 14, 15, 16, 18, 19, 20, 21, 22, 23, 26, 27
- Plus multiple GND pins

**Recommended button mapping:**

- GPIO 4: Power/Menu
- GPIO 5: Up (optional)
- GPIO 6: Down (optional)
- GPIO 12: Show Answer
- GPIO 13: Again
- GPIO 16: Hard
- GPIO 19: Good
- GPIO 26: Easy
- Any GND: Common ground for all buttons

### Button Wiring Strategy

**Challenge:** E-ink HAT female socket sits directly on Pi's GPIO header with only 11mm clearance.
Standard Dupont connectors won't fit.

**Solution:** Solder thin wires directly to GPIO header pins.

**Steps:**

1. **Before installing HAT:**

   - Cut 28AWG silicone wires to appropriate lengths (~10-15cm)
   - Strip 2mm of insulation from one end
   - Slide 5mm piece of 2mm heat shrink tubing onto wire
   - Solder wire to the **side** of GPIO header pin (between plastic base and tip)
   - Slide heat shrink over solder joint and apply heat
   - Repeat for all button GPIO pins

1. **Wiring per button:**

   ```text
   GPIO Pin ─── [28AWG wire with heat shrink] ─── Tactile Button ─── GND
   ```

1. **After wiring:**

   - Install 11mm spacers
   - Plug HAT onto GPIO header (wires route out the side)
   - Screw HAT to spacers

**Key points:**

- Thin wires (28AWG) fit easily in 11mm gap
- Heat shrink prevents shorts between adjacent pins
- Internal pull-up resistors enabled in software (no external resistors needed)
- Solder joints must be small and neat (~1mm diameter)

### Assembly Steps

1. **Attach PiSugar 3 to Pi:**

   - Align PiSugar 3 PCB with Pi mounting holes
   - Press down so pogo pins contact GPIO pads on Pi underside
   - Secure with 2-4 screws

1. **Wire buttons:**

   - Solder 28AWG wires to GPIO header pins
   - Apply heat shrink to each joint
   - Label wires for easy identification

1. **Install HAT:**

   - Insert 11mm spacers into Pi mounting holes
   - Carefully plug HAT's 40-pin socket onto Pi's GPIO header
   - Route wires out the side
   - Screw HAT down onto spacers

1. **Connect battery:**

   - Plug battery cable into PiSugar 3
   - Battery can be placed beside electronics stack

1. **Final assembly:**

   - Place stack in case
   - Connect button wires to tactile buttons
   - Secure buttons in case button holes
   - Test all connections before closing case

1. **Testing:**

   - Power on via PiSugar button
   - Verify Pi boots (LEDs)
   - Test each button with multimeter or software
   - Test display updates

### Application Architecture

**Main Components:**

1. **AnkiWeb API Client**

   - Fetch cards via HTTPS
   - Sync reviews/scheduling
   - Handle authentication
   - Offline queue for reviews

1. **Card Renderer**

   - Convert HTML → PNG (via wkhtmltoimage)
   - Support images, formatting, Kanji
   - Render to 800×480 1-bit B&W
   - Cache rendered cards

1. **Display Manager**

   - Update e-ink via Waveshare library
   - Use partial refresh (0.4s) for cards
   - Full refresh every 10-20 cards (clear ghosting)
   - Framebuffer rendering for efficiency

1. **Input Handler**

   - Read GPIO button states
   - Debounce button presses
   - Map buttons to actions
   - Handle power management

1. **State Manager**

   - Track current card, session progress
   - Battery monitoring (via PiSugar I2C)
   - RTC time management
   - Settings persistence

### Example Code Snippets

**Card rendering:**

```python
import subprocess
from PIL import Image
from waveshare_epd import epd7in5_V2

def render_card_html(html_content):
    """Convert HTML card to e-ink image"""
    html_template = f"""
    <html>
    <head>
        <meta charset="UTF-8">
        <style>
            body {{
                font-family: 'Noto Sans CJK JP', sans-serif;
                font-size: 24px;
                padding: 20px;
                width: 760px;
            }}
        </style>
    </head>
    <body>{html_content}</body>
    </html>
    """

    with open('/tmp/card.html', 'w', encoding='utf-8') as f:
        f.write(html_template)

    # Render HTML to image
    subprocess.run([
        'wkhtmltoimage',
        '--width', '800',
        '--height', '480',
        '--encoding', 'utf-8',
        '/tmp/card.html',
        '/tmp/card.png'
    ])

    # Convert to 1-bit B&W for e-ink
    img = Image.open('/tmp/card.png').convert('1')
    return img

def display_card(epd, image):
    """Update e-ink display with partial refresh"""
    epd.init()
    epd.display_Partial(epd.getbuffer(image))
```

**Button handling:**

```python
import RPi.GPIO as GPIO
import time

# Button GPIO mapping
BUTTONS = {
    'power': 4,
    'show_answer': 12,
    'again': 13,
    'hard': 16,
    'good': 19,
    'easy': 26
}

# Setup GPIO
GPIO.setmode(GPIO.BCM)
for pin in BUTTONS.values():
    GPIO.setup(pin, GPIO.IN, pull_up_down=GPIO.PUD_UP)

# Button debounce and read
def wait_for_button():
    """Wait for any button press with debouncing"""
    while True:
        for name, pin in BUTTONS.items():
            if GPIO.input(pin) == False:  # LOW when pressed
                time.sleep(0.05)  # Debounce
                if GPIO.input(pin) == False:
                    return name
        time.sleep(0.01)
```

            headers={'Authorization': f'Bearer {self.auth_token}'}
        )
        return response.ok

## Troubleshooting

### Display Issues

**Problem:** Display not updating

- Check FPC cable connection between display and HAT
- Verify HAT is properly seated on GPIO header
- Check power supply (5V, sufficient current)
- Run Waveshare example code to test hardware

**Problem:** Slow refresh or ghosting

- Confirm you have V2+ HAT with partial refresh support
- Use `display_Partial()` instead of `display()` for fast refresh
- Perform full refresh every 10-20 cards to clear ghosting
- Check display temperature (e-ink performs poorly below 10°C)

### Button Issues

**Problem:** Buttons not responding

- Check wire connections to GPIO pins
- Verify GPIO pin numbers in code match physical wiring
- Test with multimeter (pin should read LOW when button pressed)
- Check for shorts between adjacent pins (use heat shrink)

**Problem:** Multiple button presses detected

- Increase debounce delay in code (try 100ms)
- Check for electrical noise or loose connections

### Power Issues

**Problem:** Device won't power on

- Check battery charge level
- Verify PiSugar pogo pins are making contact with Pi
- Try connecting USB power directly to Pi
- Check PiSugar power button (press and hold)

**Problem:** Short battery life

- Check for background processes consuming CPU
- Reduce display refresh frequency
- Verify Pi is sleeping between card reviews
- Check for WiFi/Bluetooth staying active unnecessarily

### Software Issues

**Problem:** Cards not rendering correctly

- Verify wkhtmltoimage is installed
- Check HTML template syntax
- Verify Noto CJK fonts are installed
- Test HTML rendering manually: `wkhtmltoimage test.html test.png`

**Problem:** AnkiWeb sync failing

- Check WiFi connection
- Verify AnkiWeb credentials
- Check firewall/network settings
- Review sync logs for error messages
